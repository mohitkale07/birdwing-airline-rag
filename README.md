# Birdwing Airlines RAG Demo

A learning project that ingests three fictional, AI-generated Birdwing Airlines
PDFs and answers policy questions using hybrid retrieval, reranking, and an LLM.
The sample documents are fictional and are not real airline policies.

## Requirements

- Python 3.11
- A NVIDIA API key to generate answers

The sample PDFs are included in `data/raw`. Ingestion downloads/loads the
embedding models used by Docling, Sentence Transformers, and FastEmbed; the
first run may take some time and require an internet connection.

## Setup on Windows

From the project root, run:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```

Add your NVIDIA API key to `.env`. Never commit `.env` or share your API key.

## Ingest and build the local vector store

Run the ingestion steps in order:

```powershell
python -m src.ingestion.run_pipeline
python -m src.vector_store.ingest_qdrant_hybrid
```

The first command reads all PDFs in `data/raw`, chunks them, creates dense
embeddings, and writes `data/processed/chunks.json` and
`data/processed/embeddings.npy`. Each PDF must have an entry in
`DOCUMENT_ACCESS` in `src/ingestion/run_pipeline.py`; this is where its source
category and allowed roles are configured.

The second command creates the local hybrid Qdrant collection in
`data/qdrant_hybrid`. **It recreates that collection**, so rerunning it replaces
the current collection contents.

Generated chunks, embeddings, and local vector database files are ignored by
Git. They are regenerated by running these steps after cloning.

## Ask a question

```powershell
python -m src.generation.answer_question
```

Choose a demo role and enter a question when prompted. The role prompt is only
for local experimentation; it is not authentication. Do not expose this
role-selection flow as a public API until roles are derived from a trusted,
authenticated user identity.

## Evaluation

Evaluation scripts and test cases are in `src/evaluation` and
`data/evaluation`. The checked-in scored reports are snapshots from an earlier
Flykite-named sample corpus. Review/update the expected document names, facts,
and pages in the test cases before treating those scores as validation for the
included Birdwing PDFs.

## Project limitations

This is a learning/demo project, not a production service. It does not yet
provide an API, authentication, rate limiting, or production-grade monitoring.
